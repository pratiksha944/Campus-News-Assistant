# Campus News Assistant

An AI-powered Campus News Assistant designed to help students find campus news, announcements, and student-related updates in one place.

## Live Demo

🌐 **Try the app:** https://campuspulse-student-news-campus-assistant-306370132410.asia-southeast1.run.app/

## Features

- Student-friendly chat interface for asking campus-related questions.
- Helps users find campus news and updates quickly.
- AI-powered responses to user questions.
- Accessible through a web browser.

> Note: The accuracy and availability of responses depend on the information and services connected to the deployed app.

## Getting Started

### Use the live app
1. Open the [Campus News Assistant](https://campuspulse-student-news-campus-assistant-306370132410.asia-southeast1.run.app/).
2. Enter a campus-related question in the chat.
3. Review the response and ask follow-up questions as needed.

### Source code
Browse the project files in this repository. The application was created with Google AI Studio. To modify or run the source locally, check the project files for the framework, scripts, and any required environment variables before starting.
